Link previews and media for hasht · Updated November 7, 2026

Why you may see a request

Hashtbot fetches pages and media for links shared in hasht chats. It reads page metadata to build previews and proxies images and videos so viewers do not have to connect directly to the linked website for those previews.

Identity

The embed preview fetcher identifies itself with this HTTP user agent:

Hashtbot/1.0 (+https://hasht.net/bots)

The bot name is Hashtbot. Older versions may use a different user agent.

What it fetches

  • Pages linked in chats, including redirects, to read titles, descriptions, and preview metadata.
  • Associated metadata endpoints used to build previews.
  • Image headers to determine dimensions, and images or videos displayed through the media proxy. Video playback may make range requests.

Requests support previews and media shown in chats, including when people view shared links again. This fetcher does not crawl links recursively or build a web search index. It is separate from hasht's AI-agent web fetching.

Preview results are cached to reduce repeated fetching. Requests come from the chat server, rather than forwarding the viewer's IP address to the destination website.

Who operates it

Hasht LLC operates Hasht Cloud. Independent operators can also run the hasht chat software on their own servers. Those servers may use the same Hashtbot user agent.

A user-agent string alone does not prove that a request came from Hasht LLC. This page does not assert verified-bot status with any provider. We do not currently publish an outbound IP list or signing-key directory here.

For website operators

If you need help identifying requests, reporting abuse, or requesting a change to access from our operated service, email abuse@hasht.net. Include the request time and time zone, source IP address, requested URL, and user agent if available. Please remove sensitive URL parameters before sending.

For independent self-hosted servers, their operator controls outbound traffic. The shared user agent does not identify which organization operates a particular server.
